# 小鱼Ai短剧生成系统

小鱼Ai短剧生成系统面向普通用户仅提供 **高质量、标准、省钱** 三种生产模式，同时保留剧本、角色、场景、导演规划、分镜和生产工作台等专业能力。

所有文本、图片、视频和语音模型调用统一接入独立平台 **小鱼智算中心**。模型供应商、真实模型、价格、策略版本、主备通道和上游密钥不暴露给普通用户。

- 当前版本：P2
- 小鱼智算中心版本：0.2.0
