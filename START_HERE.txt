小鱼Ai短剧生成系统 P4
=======================

1. 安装 Git、Node.js 22 x64、Yarn 1.x、Python 3.12+。
2. 双击 Build_Xiaoyu_Drama_Auto.cmd。
3. 输入已部署的小鱼智算中心 HTTPS 地址。
4. 脚本自动取得锁定源码、应用 P4、下载 FFmpeg、执行类型检查并生成 Windows setup.exe。

软件内用户流程：
登录小鱼智算中心 -> 创建项目 -> 选择高质量/标准/省钱 -> 确认剧本 -> 一键生产 -> 查看粗剪 MP4。
